🗾 Tokyo Life — Personal Website
Java · Spring Boot · Spring MVC · Thymeleaf · MyBatis · PostgreSQL 기반 개인 홈페이지
도쿄에 거주하는 한국인의 시선으로 일본의 여행과 생활 경험을 공유하는 개인 홈페이지입니다.
직접 방문한 장소와 일상을 글과 사진으로 기록하고, 방문자는 콘텐츠를 읽고 비회원 댓글로 이야기를 나눌 수 있습니다.
첫 버전은 한국어 콘텐츠와 관리자 기능을 중심으로 개발합니다. 실제 배포·운영을 거쳐 일본어 콘텐츠, 장소 안내, 상품 판매 등으로 단계적으로 확장할 계획입니다.
진행 상태: 요건정의 및 DB 설계 준비 단계
아래 기능은 개발 예정입니다. 대화에서 확인한 화면 예시는 디자인 검토용이며, 실제 Java 서버·DB 연동이나 운영 배포가 완료된 상태는 아닙니다.
서비스명은 가칭이며 저장소 이름은 tokyo-life-blog를 유지합니다.

🎯 프로젝트 목적
- 직접 작성한 일본 여행·생활 콘텐츠를 꾸준히 공개하고 운영합니다.
- Java MVC 기반으로 요건정의 → 화면·DB 설계 → 구현 → 테스트 → 배포 → 운영 과정을 경험합니다.
- 기존 Java 코드·SQL·로그 분석과 테스트 경험을 직접 설계·구현하는 역량으로 확장합니다.
- 데이터 정합성, 인증·인가, 예외 처리, 파일 관리와 운영 문제를 해결한 근거를 기록합니다.

💬 비회원 댓글 정책
확정된 방향
- 방문자는 닉네임, 내용, 수정·삭제용 비밀번호를 입력하여 댓글을 작성합니다.
- 수정·삭제 요청 시 서버가 해당 댓글의 비밀번호를 검증합니다.
- 비밀번호 원문은 저장하지 않으며 비밀번호 해시를 저장합니다.
- 닉네임은 사용자 신원 확인 수단으로 사용하지 않습니다.
- 댓글은 일반 텍스트로 처리하며 HTML 입력을 실행하지 않습니다.
- 비밀번호를 잊었을 때 자동 복구할 수 없다는 안내를 제공합니다.
설계 시 확정할 제안
- 관리자 승인 후 공개하며, 공개 댓글을 수정하면 재승인 대기로 전환합니다.
- 댓글 작성과 비밀번호 확인에 요청 빈도 제한을 적용합니다.
- 닉네임·댓글 길이, 비밀번호 최소·최대 길이와 공백 입력 처리 기준을 정합니다.
- 운영자 답글의 포함 여부와 원댓글 삭제 시 답글 처리 규칙을 정합니다.
승인 정책과 운영자 답글은 검토 중인 항목이며 구현 완료 기능이 아닙니다.

구체적인 버전은 프로젝트 생성 시 지원 상태와 상호 호환성을 확인한 뒤 고정합니다.
선택 이유
- Spring MVC + Thymeleaf: 하나의 애플리케이션에서 요청, Java 처리, DB 조회, 화면 표시를 연결합니다.
- MyBatis: SQL·JOIN·검색 조건과 트랜잭션 처리를 직접 학습합니다.
- PostgreSQL: 기존 학습 경험을 활용하고 개발·통합 테스트·운영의 DB 계열을 통일합니다.
- 세션 인증: 동일 사이트의 관리자 로그인 요구에 맞춰 구성합니다.
- Gradle: 이전 개인 프로젝트 경험을 이어서 빌드·의존성 관리를 학습합니다.
- 단일 애플리케이션: 기능별로 코드를 나누면서 하나의 배포 단위로 시작합니다.
Spring MVC는 JSON API에도 사용할 수 있습니다. 이번 프로젝트는 HTML 화면 중심으로 시작하고 필요할 때 JSON API를 추가합니다.
🏗 애플리케이션 설계 방향
계층	책임
Controller	요청 수신, 입력 검증 결과 처리, Service 호출, 화면 선택·리다이렉트
Service	공개 조건·권한 관련 업무 규칙, 트랜잭션 경계
Mapper	SQL 실행과 결과 매핑
View	Thymeleaf를 통한 HTML 표시


- 글과 태그 연결처럼 함께 성공해야 하는 DB 변경은 하나의 트랜잭션으로 처리합니다.
- 비공개 글은 공개 목록·검색·상세에서 노출하지 않습니다.
- 사진 파일은 영속 저장소에, 파일 참조와 메타데이터는 DB에 저장합니다.
- 파일 저장은 DB 트랜잭션과 별개이므로 저장 실패와 고아 파일 정리 절차를 설계합니다.
- 관리자 화면 접근뿐 아니라 변경 요청 자체에도 서버에서 권한을 확인합니다.

🧪 테스트·품질 계획
- 공개 글만 조회되고 비공개 글·사진 접근이 차단되는지 확인
- 비로그인 사용자의 글 변경 요청과 잘못된 입력 확인
- 글·태그 저장 실패 시 트랜잭션 롤백 확인
- 댓글 비밀번호 불일치 시 수정·삭제가 차단되는지 확인
- 다른 댓글 ID로 요청을 바꿔도 권한 확인을 건너뛸 수 없는지 확인
- 사진 형식·용량 검증과 저장·삭제 실패 처리 확인
- PostgreSQL에서 JOIN·제약조건·검색·페이지 결과 확인
- 모바일에서 글 조회·댓글 작성·수정·삭제 흐름 확인
CSRF 보호, SQL 파라미터 바인딩, 출력 이스케이프와 편집기 본문 정제를 적용할 계획입니다.

- PR에 변경 이유, 검증 결과, DB 변경 영향을 기록하고 검토 후 병합합니다.
- 기능과 함께 필요한 테스트를 작성하고 CI로 빌드·테스트를 확인합니다.
- 구현 예정·완료를 구분하고 설계 결정과 운영 개선 내용을 기록합니다.
🌱 향후 확장
- 일본어 메뉴와 게시글 번역본 제공
- AI 번역 초안 생성 후 관리자 검토·공개
- 방문 장소 목록·지도 탐색
- 실제 필요가 생기면 회원 기능 도입
- 중고 물품 또는 일본 상품의 한국 판매
판매는 판매 방식·재고·주문·결제·배송·취소 요구사항을 별도로 정의한 뒤 개발합니다.
