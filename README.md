# 🗾 Tokyo Life

東京での旅行・生活体験を発信する個人ブログです。  
도쿄에 거주하는 한국인의 시선으로 여행·맛집·생활 경험을 공유하는 개인 블로그입니다.

**Java 21 · Spring Boot · Spring MVC · Thymeleaf · MyBatis · PostgreSQL**

## 日本語での紹介

### 概要

Java・Spring Bootを使用して開発している個人のWebアプリケーションです。運営者が東京での旅行・生活に関する記事を投稿し、訪問者が閲覧できるブログを目指しています。

Spring MVCとThymeleafによる画面表示、MyBatisによるDBアクセスを通じて、要件整理・DB設計から実装・テスト・デプロイまでを学んでいます。

### 現在の進捗

**開発中です。ローカル環境で投稿一覧・詳細の表示を確認しています。**

- ER図・テーブル定義の初期設計
- Spring BootとPostgreSQLの接続
- MyBatisによる投稿データの取得
- 基本的なThymeleaf画面での投稿一覧・詳細表示

現在の画面は動作確認用の簡易的なものです。画面デザイン、CSSによるスタイリング、モバイル対応は今後進める予定です。運用環境へのデプロイはまだ行っていません。

### 今後の実装予定

- 投稿の作成・編集・削除
- 入力検証・例外処理
- 管理者認証・アクセス制御
- カテゴリ・タグ、検索、ページネーション
- 画像アップロード・非会員コメント
- 画面デザインの整備、テストの追加、デプロイ

### 開発の目的

実務で経験したJavaコード・SQL・ログの調査やテストを土台に、Webアプリケーションを自分で設計・実装する力を身につけることを目指しています。

## 한국어 소개

### 프로젝트 개요

직접 방문한 장소와 일상 경험을 글과 사진으로 기록하기 위한 개인 블로그입니다.

첫 버전은 운영자 한 명이 게시글을 관리하고, 방문자는 회원가입 없이 공개 글을 읽는 형태로 개발합니다. 이미지와 비회원 댓글 기능은 이후 추가할 예정입니다.

초기 콘텐츠는 한국어로 작성하며, 일본어 콘텐츠는 향후 확장 항목으로 고려하고 있습니다.

### 개발 목적

- Java MVC 구조에서 요청 처리부터 DB 조회, 화면 표시까지의 흐름을 이해합니다.
- 요건 정리 → DB 설계 → 구현 → 테스트 → 배포 과정을 경험합니다.
- 기존 코드 분석·SQL 검증 경험을 직접 기능을 설계하고 구현하는 역량으로 확장합니다.
- 구현 중 발생한 문제와 해결 과정을 기록합니다.

## 기술 선택 이유

- **Spring MVC + Thymeleaf:** 서버의 요청 처리와 DB 조회 결과를 HTML 화면까지 연결하는 흐름을 학습하기 위해 선택했습니다.
- **MyBatis:** SQL을 직접 작성하며 조회 조건, 테이블 관계와 데이터 매핑을 이해하기 위해 선택했습니다.
- **PostgreSQL:** 관계형 데이터베이스의 제약조건과 트랜잭션을 학습하기 위해 사용합니다.
- **Docker:** 로컬에서 PostgreSQL을 컨테이너로 실행하기 위해 사용합니다.

## 애플리케이션 구조

기능별로 아래 계층의 역할을 구분하며 개발합니다.

| 계층 | 역할 |
| --- | --- |
| Controller | 요청을 받아 Service를 호출하고 결과를 화면에 전달 |
| Service | 기능의 처리 흐름과 업무 규칙 담당 |
| Mapper | SQL 실행 및 조회 결과 매핑 |
| View | Thymeleaf로 데이터 표시 및 입력 화면 구성 |

게시글 작성·수정·삭제를 구현하면서 입력 검증, 예외 처리와 트랜잭션 적용을 보완할 예정입니다.

## 데이터베이스 설계

초기 ERD와 테이블 정의에는 아래 테이블을 포함했습니다.

| 테이블 | 역할 |
| --- | --- |
| `users` | 관리자 계정 |
| `posts` | 게시글과 공개 상태 |
| `categories` | 게시글 카테고리 |
| `tags` | 지역·주제별 태그 |
| `post_tags` | 게시글과 태그의 연결 |
| `post_images` | 게시글 이미지 정보 |
| `comments` | 비회원 댓글 |

테이블 설계 완료와 해당 기능의 구현 완료는 구분합니다. 세부 컬럼과 제약조건은 기능 개발 과정에서 보완할 수 있습니다.

## 구현 예정 기능

### 방문자

- 공개 게시글 조회
- 카테고리·태그별 조회
- 키워드 검색 및 페이지 이동
- 비회원 댓글 작성
- 댓글 비밀번호를 통한 수정·삭제

게시글 목록·상세 조회는 기본 동작을 확인했으며, 검색·분류·댓글 기능은 추가 개발할 예정입니다.

### 관리자

- 로그인·로그아웃
- 게시글 작성·수정·삭제
- 임시저장 및 공개 상태 관리
- 이미지 업로드·삭제
- 카테고리·태그·댓글 관리

### 비회원 댓글 설계 방향

- 닉네임, 내용, 수정·삭제용 비밀번호를 입력합니다.
- 비밀번호는 원문 대신 해시로 저장할 계획입니다.
- 수정·삭제 요청 시 서버에서 비밀번호를 확인합니다.
- 댓글은 일반 텍스트로 처리할 계획입니다.

댓글 승인 정책과 운영자 답글은 검토 중이며, 아직 구현하지 않았습니다.

## 다음 개발 단계

1. 기본 입력 화면과 함께 게시글 작성·수정·삭제 구현
2. 입력 검증 및 없는 게시글 등에 대한 예외 처리
3. 관리자 로그인·권한 관리
4. 카테고리·태그·검색·페이지 이동 구현
5. 이미지·비회원 댓글 구현
6. 화면 디자인·모바일 사용성 개선
7. 테스트 보강 및 운영 배포

기능마다 최소한의 화면을 함께 연결해 동작을 확인하고, 디자인은 단계적으로 개선합니다.

## 테스트·배포 계획

앞으로 다음 항목을 검증할 예정입니다.

- 게시글 작성·수정·삭제 후 DB 반영 결과
- 빈 입력이나 존재하지 않는 게시글 요청 처리
- 공개·비공개 게시글의 접근 제한
- 관리자 외 사용자의 변경 요청 차단
- 여러 DB 변경이 필요한 처리의 트랜잭션 동작
- 댓글 비밀번호 확인과 이미지 업로드 검증

배포 환경은 아직 정하지 않았습니다. 공개 배포 전에는 환경변수 설정, HTTPS, 데이터 백업 및 재시작 후 데이터 유지 여부를 확인할 예정입니다.
